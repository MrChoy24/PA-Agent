# PA Agent — AI K线分析辅助工具（桌面端）

---

面向主观交易者的 **价格行为（Price Action）** AI 辅助决策工具。从 **Binance / OKX**（REST 公开接口，无需 MT5 终端）读取 K 线，将结构化 K 线数据与预计算特征送入大模型做**两阶段分析**（市场诊断 → 交易决策）。默认**只分析、不下单**；如需真正执行，可在设置里显式开启「自动交易」，默认仍为试运行（只记录意图，不发单）。

---

## 主要功能

- 📈 **多数据源**：Binance、OKX（REST 直连，Windows / macOS / Linux 通用，无需安装交易终端）
- 🔔 **多通道通知**：钉钉群机器人（支持加签校验与 @ 提醒）、PushPlus，下单信号可同时推送到多个通道
- 🤖 **自动交易（可选）**：Binance / OKX 现货，默认关闭 + 默认试运行，带置信度门槛、单笔/每日上限、白名单、强制止损等闸门
- 🧠 **两阶段 AI 分析**：市场诊断 → 策略路由 → 交易决策（限价/突破/市价或不下单）
- 🔄 **增量分析与持续跟踪**：新增 K 线时复用上次结论；开启 `keep_analysis` 后新 K 线收盘自动触发新一轮分析
- 🌳 **决策树可视化**：赛博科幻风格可交互流程图，自动播放闸门→策略路径动画
- 🔮 **未来走势预期**：AI 预测下一根 K 线方向和下一个市场周期位置
- 💬 **分析后自由追问**：完整对话会话管理器，实时推理流 + Token 进度条，对话历史持久化
- 📚 **经验库**：按周期位置检索历史案例供分析参考
- 📝 **完整落盘**：Prompt、原始响应、诊断/决策 JSON、Token 用量、追问记录
- 🛡️ **可配置校验体系**：JSON 校验、一致性检查、语义校验、截断修复、失败自动重试
- 🔒 **API Key** 本地加密存储

## 环境要求

| 项目     | 要求                                                                    |
| -------- | ----------------------------------------------------------------------- |
| 操作系统 | Windows 10 / 11（主支持）、macOS、Linux                                  |
| Python   | 3.11+                                                                    |
| 数据源   | Binance 或 OKX **至少一个可访问**（公开行情接口，无需 API Key）           |
| 网络     | 可访问交易所行情接口与所配置的 AI API（如 DeepSeek、PackyAPI 等）        |
