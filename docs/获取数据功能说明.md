## 获取数据（基础功能）

### 操作步骤

1. 在控制栏选择 **数据来源**（Binance / OKX）
2. 选择 **品种**（如 `BTCUSDT`、`ETHUSDT`；OKX 也可写 `BTC-USDT`）、**周期**（如 15m、1h、1d）
3. 点击 **「获取数据」** 按钮
4. 图表开始刷新，状态栏显示当前数据来源和品种信息；等待状态栏确认数据获取成功

### 数据来源说明

| 来源 | 说明 |
|------|------|
| **Binance** | 通过 `api.binance.com` 的公开 REST 接口拉取 K 线，不需要 MT5 终端、不需要 API Key；支持 1m/3m/5m/15m/30m/1h/2h/4h/6h/8h/12h/1d/3d/1w/1M |
| **OKX** | 通过 `www.okx.com` 的公开 REST 接口拉取 K 线，同样免 Key；支持 1m/3m/5m/15m/30m/1h/2h/4h/6h/12h/1d/1w/1M（无 3d / 8h） |

两个源都只用公开行情接口，**不填 API Key 也能看盘**。填写 Key 的用途是在设置里做「连接测试」和供自动交易下单使用。

### 刷新机制

- 点击「获取数据」后，程序以设定间隔（默认 **1 秒**）持续从数据源拉取最新 K 线
- 新数据到达后自动更新图表（蜡烛图 + EMA20 叠加线）
- 最新未收盘 K 线以**浅色空心蜡烛**显示，不参与 AI 分析
- **切换品种 / 周期后，刷新自动停止**，需重新点击「获取数据」才会恢复拉取

### 品种写法

- 中性写法：`BTCUSDT`（推荐），也接受 `btc/usdt`、`BTC-USDT`、`BTC_USDT`、`BTCUSDT.P`、`BTC-USDT-SWAP`
- OKX 内部自动转成 `BTC-USDT` 形态，无需手动改
- 黄金 / 外汇 / 股票代码（如 `XAUUSDm`、`600519`）会被交易所源拒绝，程序会回落成默认交易对 `BTCUSDT`

### 连接失败处理

- **网络不可达**：状态栏提示拉取失败，刷新循环自动指数退避（0.5s → 1s → 2s → … 最大 10s），恢复后自动归零
- **品种不存在**：状态栏透传交易所原始错误，如 `Binance 错误 -1121: Invalid symbol.` / `OKX 错误 51001: … doesn't exist.`
- **品种名无效**：品种输入框下方显示**红色警告**，需检查代码是否正确

### 切换数据来源

- 切换数据来源时，图表自动重置，旧数据源断开连接，当前品种/周期沿用
- 切换品种 / 周期时，图表自动重置，刷新停止，需重新点击「获取数据」
- 切换期间若有分析正在进行，分析将被取消

### 注意事项

- 品种代码必须真实存在于对应交易所，否则会返回错误而不是空图
- K 线数据不足时，图表缓冲区需要数秒填满，期间状态栏提示"数据不足"
- 刷新间隔过短可能触发交易所限流，建议不低于 1000 ms
- 两个源存在一处细节差异：**OKX 的日线按 UTC+8 对齐，Binance 按 UTC 对齐**，同一根 `1d` K 线的时间戳相差 8 小时；做跨源对比时请注意
